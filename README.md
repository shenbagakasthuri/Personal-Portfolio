# Personal Portfolio Website

A responsive portfolio built with HTML, CSS, and vanilla JavaScript for the Auspify Technologies Full Stack Development Internship — Task 1.

## Features
- Home, About, Skills, Projects, and Contact sections
- Responsive desktop and mobile navigation
- Active section navigation indicator
- Interactive project cards with detailed modal dialogs
- Project descriptions, features, and technology tags
- Subtle entrance, hover, floating, and modal animations
- Contact form validation and `mailto:` message preparation
- Accessible labels, keyboard-friendly dialogs, focus states, skip link, and reduced-motion support

## Run locally
No build tools are required.

1. Extract the project folder.
2. Open `index.html` in a browser, or run a local server from this folder. For example, if Node.js is installed, run `npx --yes http-server . -p 8000` and open `http://127.0.0.1:8000/`.
3. Keep the terminal running while previewing with a local server.


## Contact form note
The contact form validates fields and opens the visitor's default email app with a prepared message. It does not send or store messages on a backend server.
